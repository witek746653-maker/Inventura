# Inventura — Agent Instructions (overview)

Эта папка содержит набор руководств и правил для автоматизированных агентов и разработчиков, разделённых по темам. Файлы в этой папке расширяют краткие правила в `AGENTS.md` и служат как источник правок/ограничений для автоматических инструментов.

Файлы:
- `api.md` — рекомендации по взаимодействию с Supabase/эндпоинтами.
- `data.md` — формат данных, импорты/экспорты.
- `devops.md` — локальная разработка, сервис-воркеры, кеширование.
- `frontend.md` — инструкции по фронтенду и Tailwind.
- `knowledge.md` — проектные соглашения и шаблоны.
- `testing.md` — где добавлять тесты и как их запускать.

Используйте эти документы как источник правды при автоматических изменениях кода.
