# API / Синхронизация

- Все изменения, затрагивающие синхронизацию с Supabase, должны быть согласованы и не ломать форматы таблиц.
- Не вносить в репозиторий реальные ключи; пример конфигурации хранится как `config/supabase-config.example.js`.
- Не менять URL-формат или ключи полей без проверки миграции данных.
